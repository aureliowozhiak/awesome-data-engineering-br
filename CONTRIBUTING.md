# Como Contribuir

Obrigado por considerar contribuir com o **Awesome Data Engineering BR**! Este projeto existe para ser a principal referência em **engenharia de dados** em português.

## O que contribuir

- Novos recursos (cursos, tutoriais, livros, projetos)
- Correções de links quebrados
- Melhorias de conteúdo e SEO
- Traduções e correções de português
- Novos termos no glossário
- Ideias de projetos e desafios

## Como contribuir

1. Faça um fork do repositório
2. Crie uma branch (`git checkout -b feature/minha-contribuicao`)
3. Faça suas alterações seguindo o padrão existente
4. Commit com mensagem descritiva em português ou inglês
5. Abra um Pull Request descrevendo sua contribuição

## Diretrizes de conteúdo

- **Português brasileiro** em toda documentação
- Cada item deve ter contexto — não adicione apenas links
- Priorize recursos gratuitos ou de alto valor
- Evite conteúdo promocional ou spam
- Verifique se links estão funcionando

## Estrutura de pastas

Ao adicionar conteúdo expandido, use a pasta `docs/` correspondente e atualize os links internos (internal linking) no README principal e nos READMEs relacionados.

## Código de conduta

Seja respeitoso e construtivo. Contribuições que violem este princípio serão rejeitadas.
