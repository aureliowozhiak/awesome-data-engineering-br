## Por que assinar newsletters?

O ecossistema de **engenharia de dados** evolui rapidamente — novas versões de **dbt**, **Spark**, **Airflow** e serviços de **cloud** saem constantemente. Newsletters curadas economizam tempo e mantêm você relevante no mercado brasileiro.
