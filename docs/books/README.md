## Ordem de leitura recomendada

### Trilha iniciante (0–6 meses)

1. *Fundamentals of Data Engineering* — visão 360° da profissão
2. *Learning SQL* — base técnica essencial
3. *Python Crash Course* ou *Python for Data Analysis* — programação para dados
4. *The Data Warehouse Toolkit* — modelagem dimensional

### Trilha intermediária (6–18 meses)

5. *Data Pipelines with Apache Airflow* — orquestração na prática
6. *Analytics Engineering with dbt* — ELT moderno
7. *Designing Data-Intensive Applications* — arquitetura fundamental (leitura contínua)
8. *SQL Performance Explained* — otimização de queries

### Trilha avançada (18+ meses)

9. *Spark: The Definitive Guide* — processamento distribuído
10. *Kafka: The Definitive Guide* — streaming em produção
11. *High Performance Spark* — tuning avançado
12. *Data Mesh* — arquitetura descentralizada
