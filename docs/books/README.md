# Livros de Engenharia de Dados — Recomendações por Nível

> Curadoria de livros essenciais para quem quer **aprender engenharia de dados**, do iniciante ao profissional sênior.

## Nível iniciante

Livros para quem está começando a trilha de **data engineering** ou migrando de áreas adjacentes.

| Livro | Autor | Por que ler |
|-------|-------|-------------|
| *Fundamentals of Data Engineering* | Joe Reis & Matt Housley | Visão 360° da profissão — comece por aqui |
| *Learning SQL* | Alan Beaulieu | SQL do zero ao avançado |
| *Python Crash Course* | Eric Matthes | Python sólido para dados |
| *The Data Warehouse Toolkit* | Ralph Kimball | Modelagem dimensional clássica |
| *Docker: Up & Running* | Karl Matthias | Containers para pipelines |

---

## Nível intermediário

Para quem já domina SQL e Python e quer aprofundar **pipelines de dados** e ferramentas.

| Livro | Autor | Por que ler |
|-------|-------|-------------|
| *Data Pipelines with Apache Airflow* | Bas Harenslak | Airflow na prática |
| *Analytics Engineering with dbt* | Randy Abernathy | ELT moderno |
| *Designing Data-Intensive Applications* | Martin Kleppmann | Arquitetura fundamental |
| *Python for Data Analysis* | Wes McKinney | Pandas e workflow analítico |
| *Database Internals* | Alex Petrov | Como bancos funcionam por dentro |
| *SQL Performance Explained* | Markus Winand | Otimização de queries |

---

## Nível avançado

Para **engenheiros de dados** seniores e arquitetos de plataforma.

| Livro | Autor | Por que ler |
|-------|-------|-------------|
| *The Data Warehouse Ecosystem* | Various | Arquiteturas modernas de DW |
| *Spark: The Definitive Guide* | Bill Chambers | Spark completo |
| *Kafka: The Definitive Guide* | Neha Narkhede | Streaming em produção |
| *High Performance Spark* | Holden Karau | Otimização Spark |
| *The Big Book of Dashboards* | Various | Entrega de valor analítico |
| *Data Mesh* | Zhamak Dehghani | Descentralização de dados |
| *Building Machine Learning Pipelines* | Hapke & Nelson | ML + engenharia |
